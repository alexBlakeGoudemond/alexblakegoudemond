## 🌐 The IndieWeb

I've been building my own little corner of the web using the [IndieWeb](https://indieweb.org/) principles.

### Identity

**[alexblakegoudemond.com](https://alexblakegoudemond.com)**

This is my personal identity domain and IndieAuth identity.

### Website

**[absurdlygoud.com](https://absurdlygoud.com)**

This is where my actual IndieWeb content lives.

The two domains deliberately have different responsibilities:

```text
alexblakegoudemond.com
        │
        │ identity
        │ IndieAuth
        ▼
absurdlygoud.com
        │
        │ content
        ▼
     IndieWeb
```

My identity is represented using [Microformats](https://microformats.org/), with `h-card` and `rel="me"` relationships
connecting my domains and online identities.
